# Site Pati Felix (base Solox 4)

## Abrir localmente

Abra `index.html` no navegador ou sirva a pasta:

```bash
cd felix-site
npx --yes serve .
```

## Estrutura

- `index.html` — página principal (one-page)
- `css/felix-theme.css` — cores menta/lavanda (modo 2)
- `assets/` — recursos do template Solox 4 (junction)
- `assets/Patricia Felix - Logo Horizontal Branca.webp` — header transparente (hero)
- `assets/Patricia Felix - Logo Horizontal.webp` — header após scroll (fundo claro)
- `assets/Patricia Felix - Logo Vertical Branca.webp` — rodapé e menu mobile
